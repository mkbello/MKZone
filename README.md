#  MKZone – Personal Blog Platform  

A **modern, feature-rich blogging platform** built with **Node.js, Express, PostgreSQL, EJS, Bootstrap, and Vanilla JavaScript**.  
MKZone delivers a **responsive, secure, and scalable** environment for both content creators and readers.  

---

##  Tech Stack
- **Frontend:** HTML, CSS, Bootstrap, Google Fonts, JavaScript (Vanilla)
- **Backend:** Node.js, Express, EJS
- **Database:** PostgreSQL
- **Auth & Security:** bcrypt, sessions, Nodemailer (email verification & recovery)
- **Deployment:** Render

---

##  Features

### User Features
- Create, edit, and delete blog posts  
- Like articles & add comments  
- View detailed posts with smooth navigation  
- Submit contact forms  
- Manage profiles (update info, reset password, secure account deletion)  
- Confirmation modals for critical actions  

### Authentication & Security
- Secure authentication with bcrypt & session management  
- Email verification via Nodemailer  
- Password recovery & account verification  

### Admin Dashboard
- Role-Based Access Control (RBAC)  
- Manage users, posts, and comments  
- Sortable tables with confirmation modals  
- Admin moderation tools & analytics endpoints  

### Database & Performance
- Relational PostgreSQL schema for users, posts, comments, likes, and statistics  
- Cascading rules for stability & consistency  
- Real-time monitoring endpoints  
- Optimized CRUD operations
